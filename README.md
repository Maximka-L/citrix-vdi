# 🚀 Citrix Workspace Auto-Installer & VDI Repair 

Автоматизированный скрипт для тихой веб-установки, глубокой очистки и устранения ошибок подключения к **MegaFon VDI** (`vdi2.megafon.ru`, `ica2-ext.megafon.ru`) на компьютерах под управлением Windows 10 / 11.

---

## ⚡ Быстрый запуск (One-Liner для CMD / PowerShell)

Откройте диалог **«Выполнить»** (`Win + R`) или командную строку **CMD / PowerShell** и вставьте одну команду:

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/Maximka-L/citrix-vdi/main/install.ps1 | iex"
```

Скрипт автоматически запросит права Администратора, покажет ход выполнения и выполнит всю настройку под ключ.

---

## 🛠️ Что выполняет скрипт автоматически:

1. **Сертификаты безопасности (исправление SSL 61 и SSL 4):**
   - Устанавливает корневой и выпускающий сертификаты **Минцифры РФ (Госуслуги)** в хранилища `Root` и `CA`.
   - Устанавливает доверенный корневой сертификат **Sectigo AAA Certificate Services**.
   - Очищает кэши проверки отзыва (CRL/OCSP) через `certutil -urlcache * delete`.
   - Сбрасывает системный кэш DNS (`ipconfig /flushdns`).
   - Включает политику мягкой проверки отзыва сертификатов (`NoCheck`) в реестре Citrix.

2. **Звук и гарнитура (Citrix HDX Audio):**
   - Принудительно настраивает аудиокодеки и снимает ограничения полосы пропускания (`AudioBandwidthLimit = 0`).
   - Включает двунаправленную передачу звука и микрофона (`EnableAudioInput = 1`, `Audio = On`).

3. **Проверка версии и дистрибутив:**
   - Проверяет текущую версию Citrix Workspace (требуемая: `24.2.4001+` LTSR CU1).
   - Если версия устарела или отсутствует, скачивает установщик напрямую из [Releases](https://github.com/Maximka-L/citrix-vdi/releases) с наглядным прогресс-баром.

4. **Глубокая нативная зачистка (Deep Cleanup):**
   - Корректно глушит зависшие службы и процессы Citrix.
   - Вызывает штатный деинсталлятор Windows Installer.
   - Зачищает ветки реестра `HKLM`, `HKCU` и `Uninstall`.
   - Удаляет остаточные папки из `Program Files`, `ProgramData` и `AppData`.

5. **Обход блокировок антивируса 360 Total Security:**
   - Определяет активные процессы 360 Total Security (`360tray`, `360sd` и др.).
   - Приостанавливает выполнение и просит временно отключить защиту в трее, предотвращая ошибку **1603**.

6. **Чистая установка без мусора:**
   - Устанавливает только клиент ICA: отключены лишние модули App Protection, Single Sign-On (SSON), сбор телеметрии CEIP и навязчивые автообновления.
   - Принудительно ассоциирует файлы `.ica` с клиентом `wfica32.exe`.
   - Удаляет временный файл дистрибутива из `%TEMP%`.
